# 日间手记

一个可以写文字、拖入照片并自动排版的私人日记网站。

## 使用

1. 打开网站，输入设置好的日记密码。
2. 点击「写一篇新日记」，输入标题和正文。把照片拖进正文或照片区域，也可以点击选择照片，或在正文里粘贴截图。
3. 点击「保存这篇日记」。文字会按段落排版；以 `# ` 开头的行会成为小标题，以 `> ` 开头的行会成为引用，以 `- ` 开头的行会成为列表。图片会放在插入的位置。
4. 左侧留档可搜索、查看、编辑日记。底部可导出或导入加密备份。

## 数据与隐私

- 日记和照片使用浏览器的 IndexedDB 存储，并通过密码派生的 AES-GCM 密钥加密。GitHub 仓库和 GitHub Pages 不保存日记内容。
- 密码校验摘要位于公开的网站代码中。密码保护用于解锁当前浏览器中的加密留档；GitHub Pages 无法提供服务器级的访问限制。
- 不同设备和浏览器之间不会自动同步。要换设备，请在原设备导出加密备份，在新设备用相同密码解锁后导入。
- 清除浏览器站点数据可能删除留档。建议定期下载加密备份并妥善保存。忘记密码后无法解密备份。

## 本地运行

在项目文件夹运行 `python -m http.server 8765`，然后访问 `http://127.0.0.1:8765/`。加密功能需要 HTTPS 或 localhost；直接打开 `index.html` 文件不适用。

## 部署

该项目是纯静态网站。将仓库的 `main` 分支根目录作为 GitHub Pages 发布源即可。
