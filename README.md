# 日间手记

一个可以写文字、拖入照片并自动排版的私人日记网站。加密留档会自动同步到云端，在不同设备输入同一密码即可查看和修改。

## 使用

1. 打开网站，输入设置好的日记密码。
2. 点击「写一篇新日记」，输入标题和正文。把照片拖进正文或照片区域，也可以点击选择照片，或在正文里粘贴截图。
3. 点击「保存这篇日记」。文字会按段落排版；以 `# ` 开头的行会成为小标题，以 `> ` 开头的行会成为引用，以 `- ` 开头的行会成为列表。图片会放在插入的位置。
4. 左侧留档可搜索、查看、编辑日记。保存、修改和删除会同步到云端。底部可导出或导入加密备份。

## 数据与隐私

- 浏览器用密码派生的 AES-GCM 密钥加密日记和照片。加密后的内容保存在 ChatGPT Sites 的云端对象存储，GitHub 仓库不保存日记内容。
- 密码校验在云端服务中完成；公开仓库里没有明文密码或校验摘要。云端仅保存密码派生的校验值，接口有尝试次数限制。
- 原来保存在当前浏览器中的日记，会在更新后首次成功解锁时检查并上传到云端。新设备只需访问网站并输入同一密码。
- 保存需要网络连接；云端写入成功后才显示保存成功。多设备同时编辑同一篇时，最后一次保存的版本生效。
- 建议定期下载加密备份并妥善保存。忘记密码后无法解密留档或备份。

## 本地运行

项目使用 Vite 与 Cloudflare Worker。安装 Node.js 22.13+ 后运行 `npm install`。在未提交的 `.dev.vars` 中配置 `PASSWORD_SALT`、`PASSWORD_HASH` 与 `TOKEN_SECRET`，运行 `npm run dev`，访问 Vite 提示的本地地址。加密功能需要 HTTPS 或 localhost。

## 部署

同一份前端代码发布到 GitHub Pages；云端 API 和加密对象存储部署在 ChatGPT Sites。`.openai/hosting.json` 中的项目标识与 R2 绑定用于 Sites 部署，运行时密钥通过 Sites 环境变量配置，不提交到仓库。
